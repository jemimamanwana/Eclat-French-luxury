# Grace & Glamour

Website for Grace & Glamour — jewellery and wigs.

Open `index.html` in a browser to view the site (no build step).

## Pages
- `index.html` — home
- `jewellery.html` — jewellery gallery with filters and enlarge view
- `wigs.html` — wigs gallery
- `contact.html` — contact details and a form that opens WhatsApp

## Editing products
Names, descriptions and categories are in `products.js`. Photos are in `images/`.
Each "Enquire" button opens WhatsApp (+267 76 146 451) with the product name pre-filled.

To change the WhatsApp number, edit `WA_NUMBER` at the top of `main.js` (and the phone/email in the footer of each page).
